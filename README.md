# NetaBot

Bun + TypeScript + discord.js. Thin gateway — enablement + heavy work via API3.

## Setup

```bash
bun install
cp .env.example .env
# fill DISCORD_TOKEN, CLIENT_ID, API3_KEY (same as API3 API_KEY_BOT)
bun run dev
```

Slash commands are deployed from NetaBot-FE → API3, not from this repo.
